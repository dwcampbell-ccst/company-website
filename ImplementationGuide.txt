CCST Website Implementation Guide
===============================

Purpose
- Translate the 5-page wireframe PDF into the existing React + Vite + Tailwind codebase with Supabase-backed CMS (pages/posts/contact_messages) and the Vercel-style contact API.
- Deliver a modern, conversion-focused site: Home, Services, Articles, About, Contact, plus existing admin/blog infrastructure.

Tech context (current repo)
- Frontend: React 18, Vite, Tailwind, React Router (BrowserRouter). Entry: frontend/src/App.jsx with Layout + Header + routed pages.
- CMS/data: Supabase tables pages (static page content), posts (articles/blog), contact_messages (form capture). Hook usePageContent(slug) already fetches pages.
- Backend: api/contact.js (POST) writes contact_messages via service key and sends email via Nodemailer (env: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, SMTP_* , CONTACT_RECEIVER_EMAIL).
- Styling: Tailwind + custom glass/pill classes in src/index.css. Background image and Manrope font.

High-level build sequence
1) Update layout/header/footer to match wireframe CTAs and nav labels.
2) Rebuild Home page sections per wireframe.
3) Rebuild Services page with 3 offerings + download CTAs.
4) Rebuild Articles page hero + opt-in CTA; ensure posts list uses Supabase.
5) Rebuild About page content blocks.
6) Rebuild Contact page with form, contact info, topic checkboxes, and calendar widget placeholder.
7) Seed Supabase pages/posts with the new copy; wire download CTAs (direct files or gated forms).
8) QA (layout, responsiveness, forms, email/dB capture, routing).

Navigation and CTA targets
- Header links: Home (/), Services (/services), Articles (/articles), About (/about), Contact (/contact). Keep logo + tagline; add "Schedule a Consultation" button (links to /contact or calendly).
- Primary CTAs: "Explore Our Services" -> /services, "Contact Us" -> /contact, "Schedule a Consultation" -> /contact#form, "View All Insights" -> /articles.
- Secondary CTAs: download packs (link files or start gated download flow), "Book a Strategic Intro Call" -> external calendar link.

Component and data architecture suggestions
- Use a data-driven approach for services and home cards (arrays in src/pages or src/components/data/services.js).
- Create reusable components: Hero (title, subtitle, CTA buttons), SectionHeader (eyebrow + title + description), Card grid (for What We Do), Steps (for 4-step process), CTA banner, DownloadCard.
- Keep usePageContent for admin-editable rich text where useful (e.g., about body, services intro). For structured lists (services bullets), prefer code-level arrays to avoid inconsistent formatting.
- Featured Insights: optional component that queries Supabase posts limit 3; hide if empty.

Styling guidance
- Maintain glass + soft gradient background but lighten hero overlays for readability. Consider accent colors: deep green (#0f1a0f) as base text, cyan/teal (#2fb3d5) for CTAs, warm neutral (#e7efe1) for pills.
- Typography: continue Manrope; use tight uppercase tracking for labels; keep headings bold.
- Spacing: generous vertical rhythm (py-16 desktop, py-10 mobile), rounded corners (xl), subtle borders (#0000000f).
- Buttons: primary solid teal, secondary outlined dark text on light background. Ensure focus states.
- Responsive: 1 column on mobile, 2-3 columns on desktop; ensure hero text readable with gradients.
- Accessibility: semantic headings, aria-labels on buttons/inputs, form validation messages.

Data/Content setup (Supabase)
- Update pages table content for slugs: home, services, about, contact with the new hero titles/subtitles and any long-form copy you want editable.
- Seed posts with at least 3 articles to power Featured Insights and Articles list (status=published, slug, title, excerpt, content, hero_image_url, published_at).
- Confirm RLS policies already allow public read of published posts/pages.

Backend/contact wiring
- Ensure .env has SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, SMTP_HOST/PORT/USER/PASS, SMTP_FROM, CONTACT_RECEIVER_EMAIL.
- Form submission: POST /api/contact with { name, email, subject, message } (add phone/company/topic inside message body if not altering handler). On success, add a Supabase insert row and send email.
- For download CTAs, either link static files (public/downloads/...) or implement gated flow: form -> call /api/contact with subject "Clarity Pack request" then trigger file download.

QA checklist
- Navigation works on desktop/mobile; mobile menu toggles.
- All CTAs route correctly; anchor links (#strategic etc.) align with IDs.
- Home sections render without Supabase dependency (structure from code) and hide Featured Insights when no posts.
- Articles list shows Supabase content; detail page renders HTML; empty states handled.
- Contact form validates required fields; success + error states visible; record stored in contact_messages and email delivered.
- Responsiveness verified at 320px, 768px, 1024px widths.
- SEO: set per-route <title>/<meta description> using react-helmet or Vite plugin; ensure h1 per page and descriptive alt text.
